# Bolos de Pote Gourmet - Landing Page

Uma landing page premium e focada em conversão para a venda do treinamento e e-book "Bolos de Pote Gourmet". Construída com uma estética moderna, elegante e de alto contraste (Dark/Light mode), projetada para transmitir qualidade e aumentar as vendas.

## 🌟 Visão Geral

O projeto consiste em uma página de vendas completa desenvolvida em **React 18+** utilizando **Vite**. A interface destaca o valor do produto em vez de simplesmente listar características, contendo:

- **Seção Hero Interativa:** Chamada principal com forte contraste visual.
- **Benefícios (A Base Perfeita, Gestão de Ouro, etc):** Detalhando o que a pessoa vai aprender.
- **Prova Social:** Logos estilizados de garantia e qualidade.
- **Seção de Oferta e Checkout Direto:** Preço ancorado (de 97,99 por apenas 15,97) juntamente com bônus exclusivos (Planilha de Precificação, E-book Bolo Fitness e acesso vitalício).
- **FAQ (Perguntas Frequentes):** Sistema sanfona para tirar as dúvidas mais comuns dos compradores.

## 🚀 Tecnologias Utilizadas

- **[React](https://reactjs.org/)** com Hooks
- **[Vite](https://vitejs.dev/)** para o tooling e build rápido
- **[Tailwind CSS](https://tailwindcss.com/)** para a estilização via classes utilitárias
- **[Framer Motion](https://www.framer.com/motion/)** para animações e entradas de elementos
- **[Lucide React](https://lucide.dev/)** para os ícones

## 📋 Pré-requisitos

Certifique-se de ter o [Node.js](https://nodejs.org/) instalado na sua máquina (versão 18 ou superior indicada).

## 🛠️ Como Instalar e Rodar

1. **Clone o repositório**
   ```bash
   git clone <url-do-seu-repositorio>
   cd <nome-do-diretorio>
   ```

2. **Instale as dependências**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento local**
   ```bash
   npm run dev
   ```

O servidor será iniciado na porta especificada pelo Vite (como `http://localhost:3000`).

## 📦 Scripts Disponíveis no `package.json`

- `npm run dev`: Roda a aplicação no modo de desenvolvimento.
- `npm run build`: Compila o aplicativo para produção garantindo a melhor performance e arquivos minificados na pasta `dist`.
- `npm run lint`: Inspeciona o código em busca de problemas estruturais e padronização.
- `npm run preview`: Simula a aplicação em um ambiente de produção localmente a partir da pasta `dist`.

## 🎨 Personalização de Temas

As cores principais baseiam-se em uma paleta elegante utilizando o dourado em hexadecimal `#D4AF37`, combinada com um fundo branco (Light Mode) e grafite/preto profundo `#050505` e `#0a0a0a` (Dark Mode) para conferir aspecto de modernidade e sofisticação gastronômica.
